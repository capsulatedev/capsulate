# Examples

| Folder | What it shows |
|---|---|
| [`python-requests`](python-requests) | The REST API from Python with `requests`: launch, wait, exec, destroy. No SDK needed. |
| [`ts-desktop-agent`](ts-desktop-agent) | The TypeScript SDK on a Linux desktop: accessibility tree, find-act-verify, checkpoint and rollback. |
| [`mcp-claude-desktop`](mcp-claude-desktop) | The MCP server config for Claude Desktop and Cursor. |

Every example needs an API key from the dashboard (Settings, API and Keys) in `CAPSULATE_API_KEY`. Screenshots and computer-use need a desktop template (`ubuntu-desktop`); a headless capsule answers `409` to a screenshot request.
